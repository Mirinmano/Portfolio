## 📖 Overview

This portfolio website is designed to be lightweight, fast, and responsive. It helps highlight your professional journey, technical skills, and key projects. Built with Vite for fast development and optimized performance, it’s suitable for deploying on platforms like GitHub Pages, Vercel, or Netlify.

---

## ✨ Features

- ⚡️ **Vite-powered React project** for blazing-fast development
- 🔁 **Hot Module Replacement (HMR)** support
- 🧠 **ESLint** + **Prettier** configuration for clean code
- 🔌 **Official Vite Plugins**:
  - `@vitejs/plugin-react` – Babel-based
  - `@vitejs/plugin-react-swc` – SWC-based alternative
- 📱 Fully **responsive layout**
- 🧩 Modular components for reusability

## ⚙️ Getting Started

### 1. Clone the Repository

```bash
git clone https://github.com/Mirinmano/Portfolio.git
cd Portfolio
```

### 2. Install Dependencies

```bash
npm install
```

### 3. Run the Development Server

```bash
npm run dev
```

Open your browser and visit `http://localhost:5173` to view the portfolio locally.

---

## 🚀 Usage

- Customize content in components like:
  - `src/components/About.jsx`
  - `src/components/Projects.jsx`
  - `src/components/Contact.jsx`
- Update social links and contact info in `src/data/config.js`
- Build for production:

```bash
npm run build
```
